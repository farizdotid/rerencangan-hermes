# Assets

All visual assets in this project must be either created for this project
or clearly free to use, and listed here with their license.

| Asset | Source | License |
|-------|--------|---------|
| 3D scene geometry (office, desks, beds, avatars) | Generated in code from Three.js primitives | MIT (this repo) |
| Wooden floor texture | Drawn in code on a canvas at startup (`src/scene/floorTexture.ts`) | MIT (this repo) |
| Name labels, "zzz" icon, alarm glow | Drawn in code on a canvas with local system fonts | MIT (this repo) |

No image files, external fonts, sounds, or 3D model files are shipped or downloaded.
